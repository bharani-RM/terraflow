How It Works

From plain text prompt to live AWS resources in 5 simple steps.

Step 01
🔑

Connect AWS

Securely provide your AWS credentials to authenticate with your AWS environment.

AWS Credentials → AWS
Step 02
📝

Describe Infrastructure

Enter a natural-language prompt or upload a PDF document containing requirements.

Prompt | PDF Upload
Step 03
⚡

Generate Terraform

AI analyzes your requirements and builds valid, formatted HCL code.

resource "aws_instance" {}
Step 04
💻

Review & Edit

Inspect the generated code, view resource summaries, and edit in the IDE editor.

Monaco Code Editor
Step 05
🚀

Deploy to AWS

Execute Terraform commands line-by-line and monitor real-time infrastructure creation.

Terraform → AWS
